# Test reports

Each software test report (STR) records one run of both unit suites, the trace check, coverage, scans and metrics at a named commit. Reports are generated by `python3 -S -B -m tools.gen_release_docs --pr <N>` on a clean checkout and committed unchanged. See [test plan TP-5](../test-plan.md#tp-5--release-records).
