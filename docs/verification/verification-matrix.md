This matrix traces every [requirement](../requirements/requirements.md) to the tests or procedures that verify it (NPR SWE-052). Run the suites from the repository root:

```sh
python3 -S -B -m unittest discover -s tests -t .
python3 -S -B -O -m unittest discover -s tests -t .
```

Trace check: `python3 -S -B -m tools.check_trace` (also run inside both suites by `tests/test_trace.py`). It fails on a requirement without a row, a row naming a missing test, a test that is neither traced nor listed below, a design component without a requirement, a data-dictionary omission or a dead link. Its counts at each tested commit are in the [test reports](reports/README.md).

T = automated test, D = demonstration by a numbered test-plan procedure. These are author-written synthetic contract tests, not independent mathematical acceptance. "Last result" points to the test report for the most recent recorded run; a result does not carry over to a later tree. Untested behaviour is listed in [SRS §9](../requirements/requirements.md#9-untested-behaviour-requirement-gaps), not here.
