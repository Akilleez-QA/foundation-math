# Version descriptions

Each version description (VDD) identifies one recorded source candidate: commit, contents, digests, changes and open problems. No release tag exists; candidates are named by `PACKAGE.json` `candidate`. VDDs are generated by `python3 -S -B -m tools.gen_release_docs --pr <N>` together with the matching [test report](../verification/reports/README.md).
